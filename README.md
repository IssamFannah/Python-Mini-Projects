# 🚀 Python Mini Projects - Day 1

A collection of small projects and simple applications built during my first day of learning Python.

## 📁 Repository Contents:

* **First_Code.py**: A simplified student grading system that evaluates pass/fail status based on specific conditions.
* **Store.py**: A retail store program that calculates discounts for loyalty card holders and adds Value Added Tax (TVA) to compute the final price (TTC).
* **game_level_up.py**: An interactive gaming application that tracks player points and triggers a "Level Up" once the player hits 100 points.
* **TTC.py** and **TTC_2**: A quick financial calculator in French to convert prices from net price (Prix HT) to total price including tax (Prix TTC).

## 🛠️ Technologies Used:
* Python 3
* Conditionals ('if', 'else')
* User Input & Data type conversion ('int', 'float')
* String Formatting ('f-strings')
